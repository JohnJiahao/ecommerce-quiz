# 电子商务题库 · 期末复习练习系统

一个**单文件、纯前端**的电子商务期末刷题页面。打开就能做，不用装环境、不用登录、不上传任何数据。

- 在线版：<https://johnjiahao.github.io/ecommerce-quiz/>
- 题库规模：**70 题** —— 单选 25 / 多选 22 / 填空 10 / 论述 13（含 3 道图片题）

---

## 怎么用

### 1. 直接打开

下载 `index.html`，双击用浏览器打开即可（Chrome / Edge / Firefox / Safari 都行）。
没有网络也能用，所有逻辑都在这一个文件里。

### 2. 选模式

| 模式 | 说明 |
|---|---|
| **顺序做题** | 单选 → 多选 → 填空 → 论述，全部题型按顺序过一遍 |
| **随机做题** | 先选题型，再从该题型里随机抽 10 题（论述题会全部给出） |

### 3. 做题

所有题型都是「先作答 → 点 **确认答案 ✓**」：

- **单选**：点一个选项
- **多选**：勾选所有正确项（少选/多选都算错）
- **填空**：一空一空填，`__1__`、`__2__` 对应第几个空
- **论述**：文本框写答案，确认后显示参考答案，**自己对照评判**

确认后立即显示对错和正确答案。不会就先点「跳过」，会直接给答案，不计分。
想回头再看：点 **☆ 收藏**，首页「⭐ 收藏夹」里能重做。

### 4. 快捷键

| 按键 | 作用 |
|---|---|
| `←` / `→` | 上一题 / 下一题 |
| `Enter` | 下一题（填答案时不会误触发） |

光标在输入框里时，方向键不会翻页。

### 5. 交卷

答完点「📋 交卷」，出成绩页：

- 总正确率、等级评语
- **各题型得分**（论述题标注「自行评判」）
- 点任意一题可**回顾**：看题干、你的答案、正确答案
- 「重新开始」重置本轮

收藏夹存在浏览器 `localStorage`（键名 `ecommerce_quiz_fav`），换浏览器或清缓存会丢。

## 本地部署

### 方式 A：直接开文件

```bash
git clone https://github.com/JohnJiahao/ecommerce-quiz.git
cd ecommerce-quiz
# 双击 index.html，或：
start index.html
```

### 方式 B：Docker（nginx）

```bash
docker build -t ecommerce-quiz .
docker run -d -p 8080:80 ecommerce-quiz
# 浏览器打开 http://localhost:8080
```

`Dockerfile` 只是把 `index.html` 拷进 `nginx:alpine`，没有构建步骤。

### 方式 C：GitHub Pages

仓库 Settings → Pages → Source 选 `main` 分支根目录，保存后访问
`https://<你的用户名>.github.io/ecommerce-quiz/`。

## 自己加题

题库写在 `index.html` 里的四个数组，结构很简单：

```js
// 单选：a 是正确选项下标（0 开始）
var singleBank = [
  {q:"题干……", o:["选项A","选项B","选项C","选项D"], a:1}
];

// 多选：a 是正确选项下标数组
var multiBank = [
  {q:"题干……", o:["A","B","C","D"], a:[0,2,3]}
];

// 填空：题干里用 __1__ __2__ 标空，a 按顺序给答案
var fillBank = [
  {q:"域名的特征：__1__、__2__、__3__。", a:["唯一性","排他性","标识性"]}
];

// 论述：r 是参考答案；有图就加 img 字段
var essayBank = [
  {q:"……", r:"参考答案……", img:"img-set.jpeg"}
];
```

加完保存刷新即可，页面上不用改任何东西。
